## Coverage rules

- Every source requirement must have at least one planned milestone and observable verification evidence.
- Security and tenant boundaries require negative and concurrency cases where applicable, not only success-path assertions.
- A milestone is not verified merely because another milestone is expected to cover the requirement; record evidence in the milestone completion record.
- If a requirement is constrained or deferred, the architecture rationale and the affected future extension must be explicit. No currently approved acceptance requirement is deferred by this matrix.
