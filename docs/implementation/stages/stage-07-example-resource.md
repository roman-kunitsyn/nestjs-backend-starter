# Stage 07 — Example Resource

**Objective:** Demonstrate complete reusable tenant-scoped CRUD with ownership policies, validation, pagination, API documentation, and isolation tests.

**Prerequisites:** Stage 06. **Milestones:** M016. **Outcome:** A working reference module for future business features.

## Exit criteria

- The resource has organization-consistent foreign keys and tenant-scoped repository methods.
- Authorized CRUD, ownership behavior, cursor pagination, filtering/sorting validation, and OpenAPI work.
- The reusable tenant isolation matrix passes for at least two organizations.
